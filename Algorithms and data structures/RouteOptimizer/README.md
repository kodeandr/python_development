## Описание задачи
Программа решает задачу многокритериальной оптимизации маршрутов между городами.
Для каждого запроса находит:
1. Три оптимальных маршрута по отдельным критериям (длина, время, стоимость)
2. Один компромиссный маршрут на основе заданных приоритетов

## Используемые алгоритмы и структуры данных

### 1. Алгоритм Дейкстры
**Назначение**: Поиск кратчайшего пути в графе с неотрицательными весами
**Реализация**: Используется для нахождения оптимальных маршрутов по каждому критерию

**Сложность**:
- Временная: O((V + E) * log V)
  - V - количество вершин (городов)
  - E - количество рёбер (дорог)
  - log V - стоимость операций с кучей (priority queue)
- Пространственная: O(V + E)
  - Хранение графа: O(E)
  - Хранение расстояний и предков: O(V)

**Оптимизации**:
- Используется двоичная куча (heapq) для эффективного выбора следующей вершины
- Проверка на уже обработанные вершины для избежания повторной обработки
- Хранение полных параметров пути для каждого узла

### 2. Лексикографическая сортировка
**Назначение**: Выбор компромиссного маршрута на основе приоритетов

**Алгоритм**:
1. Фильтрация существующих маршрутов
2. Создание кортежей значений по приоритетам
3. Сортировка кортежей в лексикографическом порядке
4. Выбор первого (наилучшего) маршрута

**Сложность**:
- Временная: O(N log N), где N ≤ 3 (количество критериев)
- Пространственная: O(1)
